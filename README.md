# nikodem.work

Personal site of Nikodem Cabała. One continuous voyage: a sailboat crosses a night sea and reaches harbour as you scroll, while the day breaks around it.

## Stack

Vite, React 19, TypeScript, SCSS, React Three Fiber, drei, postprocessing, GSAP ScrollTrigger, Lenis.

## Run

```bash
yarn
yarn dev
```

`yarn build` type-checks and produces `dist/`. Deployed on Vercel from `main`.
